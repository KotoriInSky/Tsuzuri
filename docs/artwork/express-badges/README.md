# 快递岛承运商自绘徽标

口令岛识别到快递单号、且设备上没装承运商官方 App 时，展开态左侧 224×224px 方图位用这套自绘徽标。
装了官方 App 时仍用 App 图标（由 PackageManager 当场取，不进仓库）。

- 数据：`core/src/main/kotlin/io/github/kotoriinsky/tsuzuri/core/ExpressBadge.kt`（`Glyph` / `Style` / 承运商表）
- 绘制：`hook/src/main/java/io/github/kotoriinsky/tsuzuri/hook/feature/passcodeisland/ExpressBadgePainter.kt`
- 预览：[preview.html](preview.html)，用浏览器直接打开

## 设计思路

第一版是「渐变色块 + 一个汉字」，用户反馈「放个字上去也不行」；随后又定下**扁平风格**，
参照图标包「补全计划 One」：

- **纯色圆角底**：圆角 = 边长 × 0.25，与岛上的封面图一致；不做渐变、投影、高光、内描边。
- **图形是唯一的识别要素**，不画字。`Badge.text` 只留给无障碍描述和旧调用方。
- **统一网格与留白**：图形都画在 24×24 网格里（与 Material 图标同一网格），放进方图中间 58% 见方，四周留白相等。
- **统一线宽**：描边只有两档 —— 主线 2.2、细节 1.4（网格单位）；填充块的圆角化描边统一 1.2。单测会拦住不在档位上的线宽。
- **两色**：每家一个主色（通常白）+ 一个点缀色，点缀只用在一处，让图形有焦点。
- **镂空**（`Role.CUT`）代替「用底色描线」：擦掉图形层露出底色，底色换了也不会穿帮。
- **小尺寸可读**：岛上实际约 56dp。细节最小到 0.85 网格单位的齿孔（邮票），其余都在 1.4 以上；
  第一轮看图后改掉了三个在小尺寸下会被误读的方案（见下表「弃用」）。
- **深色岛底**：没有描边兜底，靠底色本身的明度和岛底拉开；单测要求底色最亮通道 ≥ 0x3A
  （顺丰、亚马逊、UPS 的底色因此比印象色提亮了一档）。

### 与预览的一致性

几何不在 Kotlin 和 HTML 里各写一份：core 的单测把 `Glyph` / `Style` / 承运商表序列化成 JSON，
要求与 `preview.html` 里 `/*SPEC-BEGIN*/ … /*SPEC-END*/` 之间的内容**逐字相同**。
改了图形 → 跑 `:core:test` → 按 `core/build/express-badges-spec.json` 替换预览里那一段。
两边的绘制语义也一一对应：

| Kotlin（ExpressBadgePainter） | SVG（preview.html） |
| --- | --- |
| `canvas.translate(off) + scale(k)`，k = 边长 × 0.58 / 24 | `<g transform="translate(off) scale(k)">` |
| `FILL_AND_STROKE` + 圆角连接 | `fill` + 同色 `stroke`，`stroke-linejoin=round` |
| `Paint.alpha` | 元素 `opacity`（整体合成，交界不叠深） |
| `DashPathEffect([0.01, 点距])` + 圆头 | `stroke-dasharray="0.01 点距"` + 圆头 |
| CUT：`DST_OUT` 擦掉图形层里**之前**画的部件 | 嵌套 `mask`，只作用于之前的部件 |

## 原创性说明

所有图形都是用 24 网格从头构造的通用意象（箭头符号、圆环、闪电、立方体、房屋、信封、邮票、
信箱、纸箱、经纬球、虚线路径、传送带、云、星芒、行李牌），没有参照、描摹或改造任何承运商的标志：

- **顺丰**：官方标志是文字标；这里是三道几何 › 符号，不含任何字母形状。
- **圆通**：没有使用其标志的任何组成部分；环线 + 圆点取自名字里的「圆」。
- **极兔**：官方标志是字母组合；这里是通用闪电，不含字母、不含兔子形象。
- **德邦**：官方标志是文字标；这里是通用等轴测立方体。
- **京东物流**：不使用其吉祥物（小狗）或任何字母；库房是通用的房屋 + 卷帘门构造。
- **邮政（四地）**：不使用任何邮政机构的徽记（含带翅膀的图形）；信封 + 圆点是通用符号。
- **日本邮便**：**刻意不使用〒记号**（它同时是日本邮便的标志）；邮票、邮戳、波浪戳线都是通用的邮政意象。
- **美国邮政**：不使用其鹰头标志；拱顶信箱是通用的信箱造型。
- **UPS**：**不使用盾形**轮廓；这里是正面纸箱 + 一条封箱带。
- **DHL**：不使用其倾斜字母与速度线；经纬球是通用的地球符号。
- **FedEx**：不使用其文字标，也**没有**字母间的负空间箭头；这里是一条没有箭头的虚线路径。
- **亚马逊物流**：**不使用笑脸弧线 / 弧形箭头**；这里是纸箱 + 传送带。
- **云途物流**：云由三个圆和一条圆角底座拼成，不参照任何品牌的云形。
- **国际件 / 通用**：星芒与行李牌都是通用符号，不对应任何品牌。

整套图形零图片资源、零字体文件，全部由 `android.graphics` 的 Canvas / Path / Paint 在运行时画出。
